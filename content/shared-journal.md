# Shared Journal Project — Vision

**Domain:** 08d5743r4qj3w.com

## Core Concept
A shared digital space — part public journal, part private sanctuary. 
Invite-only, anonymous by default. Identity revealed only in person, by choice.

## Principles
- **Anonymous relations** — invited by picobean personally, but anonymous to each other
- **Privacy by default** — each person has a private space only they (and the agent) can see
- **Public journal** — shared space where anyone can contribute, anonymously
- **Agent-mediated** — OpenClaw acts as the interface, curator, and bridge

## Architecture

### Tier 1: Public Website (done ✅)
- Quartz static site on Cloudflare Pages
- Publishes content from /public/ folder
- Anyone can view, no login needed

### Tier 2: Agent Interface (next)
- People message via Signal/WhatsApp
- OpenClaw receives messages, can read/write vault
- Agent can publish to public journal on their behalf
- Agent summarises, edits, curates

### Tier 3: Web Portal (future)
- Login via QR code invite (generated by picobean)
- Each person gets: anonymous handle, private journal, public access
- Built on CouchDB per-user databases + PouchDB in browser
- Web app with auth, reading/writing personal + public content

## User Flow
1. Picobean meets someone, generates QR invite
2. Person scans → gets anonymous account (handle, not real name)
3. They can:
   - Message the agent (Signal or web chat)
   - Read the public journal
   - Write to the public journal (anonymously)
   - Keep a private journal (only them + agent)
4. Nobody knows who anyone else is unless revealed in person

## Tech Stack
- **CouchDB** — per-user databases, already running on VPS
- **Cloudflare Tunnel** — secure access
- **Cloudflare Pages** — public static site
- **PouchDB** — browser-side sync for web portal
- **OpenClaw** — agent layer, message routing
- **Signal/WhatsApp** — messaging interface

## Infrastructure
- VPS: CouchDB + tunnel (always on)
- Cloudflare: website + DNS + tunnel endpoint
- Laptop: Obsidian vault (picobean + noddle's editor interface)
- LiveSync: for picobean + noddle only (vault editors/owners)

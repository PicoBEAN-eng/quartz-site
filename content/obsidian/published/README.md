# Public (Website Sync)

Anything in this folder is eligible for website publishing via the Quartz sync pipeline.

## Rule
- Put notes here if they should be published.
- Keep drafts/personal notes in `Private/` or elsewhere in the vault.

## Workflow
1. Move or create notes in `Public/`
2. Run in `~/Documents/quartz-site`:
   - `npm run build:obsidian`
